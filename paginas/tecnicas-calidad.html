Técnicas de Aseguramiento de la Calidad

¿Qué es el aseguramiento de la Calidad?

El Aseguramiento de la Calidad del Software (SQA) comprende las actividades destinadas a garantizar que tanto el proceso como el producto cumplan determinados criterios de calidad.

La idea no es esperar hasta el final para descubrir errores.

Técnicas de prueba

Caja Negra

La técnica de Caja Negra permite evaluar el comportamiento del software sin conocer ni analizar cómo está implementado internamente.

El tester se concentra en las entradas que recibe el sistema y en las salidas que produce, verificando que el resultado coincida con lo esperado.

¿Qué se analiza?

  • Entradas y salidas del sistema.
  • Comportamiento de las funciones.
  • Resultados esperados y obtenidos.
  • Casos correctos e incorrectos.

Ejemplo:

Introduzco usuario y contraseña → presiono “Ingresar” → compruebo si el sistema permite acceder correctamente o muestra un mensaje de error.

Caja Blanca

La técnica de Caja Blanca analiza la estructura interna del software, teniendo en cuenta cómo está construido y cómo se ejecutan sus instrucciones.

Para realizar este tipo de prueba es necesario conocer el código fuente y su lógica interna. Se busca comprobar que los diferentes caminos y condiciones del programa funcionen correctamente.

Se pueden analizar:

  • Condiciones.
  • Caminos de ejecución.
  • Instrucciones.
  • Bucles.
  • Cobertura de código.

Ejemplo:

Se analiza el código de un inicio de sesión para comprobar qué ocurre cuando los datos son correctos, incorrectos o están incompletos.

Tipos de pruebas

Pruebas funcionales

Comprueban que el sistema realice correctamente sus funciones.

Pruebas no funcionales

Evalúan características como:

  • Rendimiento.
  • Seguridad.
  • Usabilidad.
  • Compatibilidad.
  • Disponibilidad.
