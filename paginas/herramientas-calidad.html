03 — HERRAMIENTAS

Herramientas de Calidad

¿Qué son las herramientas de calidad?

Son herramientas que permiten gestionar pruebas, realizar seguimiento de errores y tareas, y analizar diferentes aspectos relacionados con la calidad del software.

JIRA

Permite registrar, asignar y hacer seguimiento de errores o tareas.

Por ejemplo, un bug puede registrarse con:

  • Descripción.
  • Prioridad.
  • Versión.
  • Capturas.
  • Estado.
Ver más

GitHub Issues

Permite registrar y hacer seguimiento de:

  • Errores.
  • Tareas.
  • Mejoras.
  • Ideas.
  • Solicitudes.

También permite organizar el trabajo mediante proyectos, etiquetas, responsables y otras características.

Ver más

TestRail

Está orientado a la gestión de pruebas.

Permite:

  • Crear casos de prueba.
  • Organizar suites.
  • Ejecutar pruebas.
  • Registrar resultados.
  • Analizar defectos.

SonarQube

Analiza código y permite detectar aspectos como:

  • Bugs.
  • Vulnerabilidades.
  • Problemas de mantenibilidad.
  • Code smells.
